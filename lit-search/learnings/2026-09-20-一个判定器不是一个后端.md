# 一个判定器不是一个后端

**问题**：接一个返回校准概率的判定 API（TypeSafe Jev），本以为是"换个更便宜的
筛选后端"。$0.042/百万输入 token、输出免费、p50 延迟 0.25 秒，比现有 LLM 便宜
一个量级。实测下来：它在一个课题上把人工队列从 18.3% 压到 11.2%，在另一个课题上
**反而比现有方案更差**（8.5% vs 7.2%，还要多误排 161 篇）。

同一套代码、同一套阈值、同一个模型版本。差别只在课题。

## approach

1. **先花二十分钟做只读探针，再动一行代码。** 两个已标注的历史 run、694 次真实
   调用、$0.025。这二十分钟把方案的重心整个挪了位置：原本打算做的"第三个筛选
   后端"降级成了需要逐课题准入的可选项，原本排在末位的"评估基座"变成了核心交付物。
2. **把"能不能用"变成可测量的问题。** 项目原本只有**检索**召回指标，没有任何
   **筛选**精度指标——于是换模型、换后端、改阈值都只能凭感觉。先建评估基座，
   再谈接入。
3. **金标与银标分开报。** 金标 = 真人裁决，银标 = 模型判定。实测某课题银标纳入
   约 21% 被真人推翻，拿它当真值算出的精度是天花板，不是真相。
4. **每个比率带 Wilson 区间。** 44 条纳入即使 100% 敏感，95% 下界也只有约 92%。
   不带区间就会把"没测出问题"讲成"证明了没问题"。
5. **不可逆漏排与进人工队列分开计数。** 错误排除那篇论文再也不会被看到，
   错误纳入只是多读一篇全文。把两者平均进一个 F1 里，等于抹掉唯一重要的区别。
6. **把准入门槛写进代码而不是文档。** 三条：金标 100% 保留、人工队列 ≤15%、
   且不劣于该课题现有基线。写在 README 里没人会照做，写成启动前的硬检查才有用。

## 判断取舍

- **没有给判定器设通用默认阈值。** 配置文件必填，缺了直接退出并说明原因。
  一个"看起来合理"的默认值会让人在没有准入证据的课题上直接放量——而那恰恰是
  实测证明会更差的场景。
- **排除标准不参与打分，只做标注。** 实测把分数乘上 `(1 - max 排除概率)` 反而
  更差（AUC 0.989 → 0.981）。官方文档也说了：一个问题与其否定式的概率不满足
  互补关系。后来在真实数据里看到一条社论——判定器给出 `X4=0.92`（正确识别为
  社论），但这个判断被 annotate 模式丢掉了，最后按纳入标准判了纳入。查了全部
  23 条高 X4 记录：硬否决能省 5 条队列，但要付最多 2 条不可逆误排。按项目的
  取舍这笔买卖不划算，所以维持现状——但**把这个反例记下来**，它说明排除标准
  确实带信号，只是用法还没找对。
- **标准原文照抄，不改写。** 实测中文原文 AUC 0.989，手写英文原子问题 0.982——
  与"英语最佳"的官方说明相反。更重要的是：一旦改写，判定依据就与协议脱钩了。
- **自动裁决只解开一类僵局，且只往一个方向。** 两个 LLM 通道互相矛盾、而判定器
  明确站在纳入一侧——这是两个不同模型族达成一致，不是让模型单方面拍板。
  只往 include 方向，因为那是可逆的那一侧。
- **摘要标注永远不说 no。** 只有 stated / not_stated。摘要没提外部验证，不等于
  这项研究没做。这条纪律由校验器强制（措辞里必须有"摘要"和"明确"），
  因为它的错法太隐蔽：产出的表看起来完全正常，只是每一个 no 都可能是假的。

## 可复用的规则

**"更便宜、更快、指标更好"三个都满足，仍然可能是更差的选择——如果你只在一个
课题上测过。** 判定质量是任务与判定器的**交互**，不是判定器的属性。换判定器之前
必须先有能量化"这次是变好还是变坏"的东西；没有它，所有关于"更好"的说法都是
在讲故事。

推论一：**评估基座要先于被评估物落地。** 它看起来像附属品，实际是唯一能让后面
每一个决定都有依据的东西。本次它是第一个写的模块，后面每一处阈值、每一条准入
门槛、每一次"这个改动值不值"都是它回答的。

推论二：**假客户端测得了你的代码，测不了服务端，也测不了运行时。** 十项 CLI
测试用 respx 全绿，真跑第一次就抛 `Event loop is closed`——httpx 的连接池绑在
创建它的事件循环上，而 respx 在传输层拦截、根本不建真实连接。补回归测试时，
先把旧写法忠实还原一遍，确认它真的会以同一个报错失败，再改回来；否则你补的
可能是一个永远不会红的测试。

推论三：**在已有数据上做的探针，成本低到没有理由不做。** $0.025 和二十分钟，
换掉的是一个会在第二个课题上翻车的方案。
