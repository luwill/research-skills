# 实测证据

SKILL.md 里的规则大多来自一次具体的翻车。这里存放那些**只在追问或排查时才需要**的
论证细节，正文只留可执行的结论。

## 期刊匹配走 ISSN，不走刊名

实测 26 本期刊的刊名匹配：错 2 本、漏 6 本。

| 语料里的刊名 | 被匹配成 |
|---|---|
| Neuroradiology | AJNR（American Journal of Neuroradiology） |
| Brain Sciences | Behavioral and Brain Sciences |

关键不是错误率，是**错配不报错**：匹配上了就取指标，谁也不会去核对。
漏配至少还会留下一个"未分层"的痕迹。所以 `rank.py` 的 `normalize_issn`
宁可拒绝一个可疑的 ISSN，也不猜。

## 引文样式名要在发请求前校验

doi.org 的内容协商对**不认识的样式名**同样返回 HTTP 200，body 是一段 JSON 错误。
不预校验的话，一千多条全跑完才发现拿到的不是引文。

这是"HTTP 200 ≠ 拿到了你要的东西"的一个实例。同一类的还有：
枚举源返回 200 但解析出 0 条；DOI 解析到出版商落地页，返回 200 + 完整 HTML。
第三个是我只挡了"见过的坏样本"（JSON 错误）导致的复发——
所以 `validate_citation` 写成"确认它是我要的"，而不是"排除我见过的坏样本"。

## 阈值过滤会误伤"没被评价过"的论文

以 4.0 为界切 1,487 条纳入集：

| | 条数 |
|---|---|
| 保留 | 390（26%） |
| 删掉但**没有任何指标** | 340 |
| 删掉但引用进入同领域前 10% | 126 |

被删的 340 条不是"指标低"，是"这条轴上测不到"——会议论文、预印本、
以及 OpenAlex 没收录期刊指标的刊。阈值把这两件事变成了同一个动作。
所以改成只标注与排序，全量交付。

## OpenAlex 的 `2yr_mean_citedness` 不是影响因子

JIF 的分母只算 citable items；OpenAlex 的分母算全部条目。
发大量学会年会摘要的期刊被系统性低估三到五倍：

| 期刊 | OpenAlex 指标 | 实际 JIF 量级 |
|---|---|---|
| Stroke | 1.81 | 8 左右 |
| Neurology | 1.11 | 9 左右 |

所以为 JIF 定的阈值**不能直接搬到这个标度上**。

## CCF 与影响力指标测的不是同一件事

Medical Image Analysis 是 CCF-C，而它的 OpenAlex 指标 10.14 是全语料最高。
所以 `assign_tier` 取所有可用尺子里**最好**的那个，而不是某一把尺子说了算。

## 滚雪球必须在筛选之后

从 13,920 条**未筛选**的窗口内记录出发，后向候选是 **134,317** 条；
而最终会被纳入的只有几百条。跳过筛选去滚雪球 = 把噪声放大一个数量级，
还要为此付十倍的筛选费。

滚雪球本身的价值同样是测出来的：饱和曲线 34.7% → 4.1% → 0.4%，
而 snowball 的独有贡献占 92%——这是纯关键词检索会漏成什么样的直接证据。

## 顶会源不能靠 OpenAlex 的 venue filter

- CVPR 的 source 按年碎片化（同一年 2,082 篇与 570 篇分属两个 source id）
- MICCAI 的 source 只有 38 篇（实际收录在 LNCS 下）
- ICLR 的 source 只有 896 篇

所以 CVPR/ICCV/WACV 走 CVF，ICLR/NeurIPS 走 OpenReview，MICCAI 走 Crossref 按卷 ISBN。

## 一个被测出来的零

CVPR/ICCV/WACV 2021–2026 约 9,200 篇里，标题命中缺血性卒中分割条件块的只有 5 篇，
且**全是假阳性**——CVF 语境下 "stroke" 是笔触（Neural 3D Strokes、StrokeFaceNeRF），
"penumbra" 是半影。

这个源的价值正是把这个零**测出来**。"我觉得那里没有"和"我查了，那里没有"
是完全不同的两句话。

## 闭源出版商的摘要覆盖靠 PubMed 撑着

| 出版商 | 语料条数 | 有摘要 |
|---|---|---|
| Elsevier | 4,546 | 95.6% |
| Springer | 2,048 | 80.4% |
| IEEE | 318 | 98.7% |

而 Crossref 上这些条目**根本没有摘要**——摘要是 PubMed / OpenAlex 供的。
非生物医学主题关掉 PubMed 后，初筛会退化成只看标题。

## 宿主后端不是免费的

`claude -p` 每次调用约 20,000 token 的框架开销（禁用全部工具后仍有
9,410 创建 + 10,589 读取）。开销**按次**算，所以批次从 25 放大到 60。

实测 60 条记录两次调用：haiku $0.295，opus $1.44，DeepSeek Flash 约 $0.02。
订阅用户不额外付费，但那是**额度内不另计费**，不是不消耗。

## 一次交付里同时藏了三个沉默的缺口

一次 `context-engineering` 主题的运行，产物看起来完整（4,018 条语料、
金标准 3/3 = 100%、2,301 篇分层交付），实际上：

| 缺口 | 当时的痕迹 |
|---|---|
| openreview / grey 一次都没访问过 | 无。manifest 声明了 4 个源，outcomes 只有 2 个 |
| 滚雪球没跑 | 无。coverage_report 里只是少了一节 |
| 捕获-再捕获不成立 | **有，但理由是错的**——硬编码成"OpenAlex 配额限制"，而 OpenAlex 跑了 3,944 条 |

第一个的成因是 `harvest --resume`：续跑用**当前**算出的源清单建 manifest，
而续跑按定义只重跑上一轮未完成的检索式，它没有能力覆盖一个从没跑过的源。

现在这三类都由 `coverage.py` 的 `find_gaps` 算出来，写进 `coverage_report.md`
的第一节，缺口为空也要写出"无"。
